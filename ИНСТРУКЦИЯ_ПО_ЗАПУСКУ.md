# ПОЛНАЯ ИНСТРУКЦИЯ: как запустить сайт Софьи

## Как устроен сайт

- `index.html` — сама страница.
- `style.css` — дизайн.
- `script.js` — интерактивность.
- `content/site.json` — тексты, услуги, отзывы, ссылки и список фотографий.
- `images/` — фотографии.
- `admin/` — твоя панель редактирования.
- `admin/config.yml` — говорит редактору, какие поля можно менять.

Главная идея: после настройки тебе НЕ нужно каждый раз лезть в код. Ты заходишь на `твой-домен.ru/admin/`, входишь в редактор и меняешь текст/фотографии через форму.

---

# ЧАСТЬ 1. Что я рекомендую

Для твоего случая я рекомендую связку:

**GitHub + Netlify + Decap CMS + свой домен**

Почему:

1. Сайт остаётся лёгким и быстрым.
2. Фотографии можно загружать через админку.
3. Тексты можно менять через админку.
4. Не нужен WordPress и отдельная база данных.
5. После публикации изменения сохраняются в GitHub и автоматически появляются на сайте.

Decap CMS — это редактор контента. Он умеет редактировать поля и загружать изображения в репозиторий. Для GitHub/Netlify используется Git Gateway. 

---

# ЧАСТЬ 2. Что тебе нужно создать

Тебе понадобятся три вещи:

### 1. GitHub

Зайди на GitHub и создай аккаунт.

Создай новый repository, например:

`sonjass-photo`

Репозиторий лучше сделать public для самого простого варианта GitHub Pages, но в предлагаемой схеме публикации через Netlify можно использовать GitHub как хранилище исходников.

### 2. Netlify

Создай аккаунт на Netlify и подключи GitHub.

После подключения выбери repository `sonjass-photo`.

В качестве сайта Netlify будет брать файлы из этого репозитория.

### 3. Домен

Можно сначала использовать бесплатный адрес Netlify, например:

`sonjass-photo.netlify.app`

А потом купить свой домен:

`sonjass-photo.ru`

или другой свободный вариант.

---

# ЧАСТЬ 3. Загрузка сайта в GitHub

После создания repository:

1. Открой repository.
2. Нажми `Add file`.
3. Выбери `Upload files`.
4. Перетащи ВСЁ содержимое этой папки.
5. Нажми `Commit changes`.

Важно: загружать нужно именно содержимое папки, чтобы в корне repository лежал:

`index.html`

а не:

`sofia_portfolio_site_v2/index.html`

В корне также должны быть:

`style.css`
`script.js`
`content/`
`images/`
`admin/`

---

# ЧАСТЬ 4. Подключение Netlify

В Netlify:

1. Add new project / Import an existing project.
2. Выбери GitHub.
3. Выбери `sonjass-photo`.
4. Build command оставь пустым.
5. Publish directory поставь `.` (корень проекта).
6. Нажми Deploy.

Это статический сайт, поэтому сборщик ему не нужен.

После публикации Netlify даст временный адрес.

---

# ЧАСТЬ 5. Самая важная часть — редактор сайта

После публикации тебе нужно включить Netlify Identity.

В настройках проекта найди:

`Integrations → Identity → Netlify Identity`

Включи Identity.

В Registration лучше выбрать:

`Invite only`

Так посторонние люди не смогут зарегистрироваться в твоей админке.

Дальше включи:

`Git Gateway`

Decap CMS использует Git Gateway как посредника между админкой и GitHub. Это позволяет тебе менять контент без прямого доступа к GitHub. 

---

# ЧАСТЬ 6. Как зайти в админку

После настройки адрес будет:

`https://ТВОЙ-САЙТ.netlify.app/admin/`

После подключения домена:

`https://sonjass-photo.ru/admin/`

Ты увидишь панель редактирования.

Там будут:

- Основная информация
- Услуги
- Категории
- Работы
- Отзывы

---

# ЧАСТЬ 7. Как менять текст

Например, ты хочешь изменить:

`ЭМОЦИИ В КАДРЕ`

Ты заходишь:

`/admin/`

→ `Сайт`

→ `Основная информация`

→ `Главный заголовок`

Пишешь новый текст.

Нажимаешь Publish.

После этого CMS сохраняет изменение в GitHub. Netlify видит изменение и обновляет сайт.

---

# ЧАСТЬ 8. Как менять фотографии

В той же панели будет поле:

`Главная фотография`

Нажимаешь выбрать изображение → Upload.

Фото загрузится в папку:

`images/uploads/`

и сайт начнёт использовать новый файл.

То же самое работает для:

- главной фотографии;
- фотографии «Обо мне»;
- фотографий категорий;
- фотографий портфолио.

Decap CMS имеет специальный image widget с медиатекой, загрузкой и выбором существующих изображений. 

---

# ЧАСТЬ 9. Как добавить новую фотографию в портфолио

В разделе `Работы` нажимаешь добавить новый элемент.

Заполняешь:

Фото:
`твоя фотография`

Категория:
`portrait`

Описание:
`Портретная съёмка`

Публикуешь.

Фото появится в галерее.

---

# ЧАСТЬ 10. Как изменить услуги

В разделе `Услуги` можно менять:

01 — ПОРТРЕТЫ
02 — РЕПОРТАЖ
03 — БРЕНДЫ
04 — МЕРОПРИЯТИЯ

Можно написать:

01 — СВАДЕБНАЯ СЪЁМКА

и поменять описание.

Никакого редактирования HTML для этого не понадобится.

# ЧАСТЬ 12. Как подключить настоящий домен

Сначала добавь домен в Netlify.

После этого у регистратора домена нужно изменить DNS.

Если используешь `www`, обычно создаётся CNAME-запись, указывающая на адрес Netlify.

Если используешь GitHub Pages напрямую, GitHub официально поддерживает собственные домены и HTTPS. Для apex-домена используются A/AAAA-записи, а для `www` — CNAME. DNS-изменения могут распространяться до 24 часов. 

Для твоего сайта я бы всё же использовал Netlify, потому что нам нужен удобный редактор контента.

---

# ЧАСТЬ 13. Что тебе НЕ нужно делать

После первоначальной настройки тебе не придётся:

- писать HTML;
- изучать CSS;
- открывать VS Code;
- вручную загружать фотографии через GitHub;
- редактировать `site.json`.

Ты просто заходишь:

`твой-сайт.ru/admin/`

и работаешь примерно как в обычной CMS.

---

# Важный момент

Для первого запуска я оставил фотографии из твоего референса как временные.

Когда ты пришлёшь мне свои реальные фотографии, я могу собрать финальную версию так, чтобы:

- фотографии были правильно обрезаны;
- у каждой категории был свой набор;
- главная фотография выглядела как в референсе;
- мобильная версия была отдельным образом адаптирована;
- появились красивые переходы;
- была форма заявки;
- можно было менять абсолютно весь текст через админку;
- можно было добавлять/удалять фотографии без кода.

Тогда сайт будет уже не просто копией макета, а полноценным рабочим портфолио фотографа.
